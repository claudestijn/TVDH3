Admin · Dienste verteilen

Geschützter Bereich für dich als Organisator. Code eingeben, um Verteilen, Namen entfernen und Befreiungen freizuschalten (leichte Sperre, kein echtes Login). Spieler können ohne Code jederzeit Namen hinzufügen und sich ein-/austragen.

Nach dem Stichtag (Ende Oktober): füllt alle noch offenen Slots automatisch — so ausgeglichen wie möglich (wenigste Dienste zuerst, niemand doppelt am selben Spieltag). Bereits eingetragene Personen bleiben unangetastet.
